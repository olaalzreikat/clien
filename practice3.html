Domain 1 Math Operations & Data Types
1
How are number variables stored in JavaScript? D1.1single
All JS numbers use the IEEE 754 double-precision floating-point format — even 5 is stored as 5.0 internally. There is no separate integer type.
2
Identify the data type of each variable D1.2single 
var a = 23;
var b = "23";
var c = true;
var d = {};
a=23 — Number (no quotes). b="23" — String (quotes make it text, not math). c=true — Boolean. d={} — Object (object literal). typeof {} returns "object", not "array."
3
Trace variable values — pre-increment & modulo D1.3single

What are the final values of x, c, a, and b?

var x = 50;
var c = ++x;       // pre-increment x first
var a = x / 2;
var b = x % 3;
Pre-increment (++x) increments before the assignment, so x becomes 51 and c receives 51. Then a = 51/2 = 25.5 and b = 51 % 3 = 0 (51 ÷ 3 = 17 exactly, no remainder).
4
Multi-variable trace with chained operations D1.3single

What are the final values of a, n, x, and y?

x = 5;
y = 2;
a = y * 8;
n = y + x;
x and y are never reassigned — they stay 5 and 2. a = 2×8 = 16. n = 2+5 = 7. A common exam trap: check whether the original variables changed — here they did not.
5
Type coercion — left-to-right evaluation D1.4single

What does this expression evaluate to?

console.log(5 + 5 + "10" + "items" + 5);
Evaluation is strictly left-to-right: 5+5=10 (both numbers), then 10+"10"="1010" (string coercion kicks in), then "1010"+"items"="1010items", then "1010items"+5="1010items5". Once a string appears, everything after concatenates as strings.
6
null vs. undefined — two-part question D1.2multi

Select both true statements.

A null is an intentional assignment representing the absence of a value
B null == undefined evaluates to true
C null === undefined evaluates to true
D undefined means the developer intentionally cleared a value
null is an intentional "no value" assignment (A ✓). null == undefined is true with loose equality because JS treats them as loosely equal (B ✓). But null === undefined is false — they are different types. undefined means declared but never assigned, not intentionally cleared.
7
Math methods: floor, round, ceil D1.3single 
Math.floor(3.5);
Math.round(4.5);
Math.ceil(5.1);
floor(3.5) always rounds down → 3. round(4.5) rounds to nearest, .5 rounds up → 5. ceil(5.1) always rounds up → 6.
8
Variable trace with post-decrement D1.3single

What are the final values of n, c, a, and d?

n = 50;
c = n / 2;       // c = ?
a = n / 4;       // a = ?
d = c * 3;       // d = ?
n = n--;         // post-decrement: n = ?
c=25, a=12.5, d=75 are set when n=50. The tricky part: n = n-- — the right side evaluates to 50 and immediately decrements n to 49. But then the assignment (=) overwrites n with that saved 50. So n ends up back at 50. If it were n-- alone with no assignment, n would be 49.

Reserved keywords — which cannot be variable names? D1.1multi

Select ALL that are reserved keywords (choose three).

A value
B while
C typeof
D return
while, typeof, and return are reserved — they have special language meaning and cannot be used as variable names. value is not reserved (it's a DOM property name, but you can use it as a variable).

typeof — including the null surprise D1.2single 
typeof 42        // → ?
typeof "hello"   // → ?
typeof true      // → ?
typeof null      // → ?
typeof null returns "object" — this is a famous JavaScript bug that has existed since 1995 and was never fixed for backward compatibility. It does NOT return "null". Always remember: typeof null === "object".

Modulo operator — pick the correct result D1.3single 
var result = 17 % 5;
The modulo (%) operator returns the remainder after integer division. 17 ÷ 5 = 3 remainder 2. So 17 % 5 = 2. (3.4 would be the result of regular division, not modulo.)
12
Global scope — multiply() with no parameters D1.3single 
var a = 5;
var b = 10;

function multiply() {
  return a * b;
}

console.log(multiply());
The function has no parameters, but it accesses globally scoped variables a=5 and b=10. It returns 50. Functions without parameters are completely valid; they simply use whatever is in scope.
Domain 2 Arrays & Array Methods
13
pop, shift, push, unshift — match each description D2.1single

Which row correctly describes all four methods?

Memory trick: push/pop work on the back/end. unshift/shift work on the front. The "un-" prefix in unshift means you're undoing the remove — i.e., adding. shift removes.
14
splice() — what does each array look like after? D2.1single

What are the values of arr and newArr after splice runs?

var arr    = ["a", "b", "c", "d", "e"];
var newArr = arr.splice(1, 2);
splice(1, 2) starts at index 1, removes 2 elements ("b", "c"), and returns the removed elements. The original arr is mutated in place. So arr = ["a","d","e"] and newArr = ["b","c"].
15
Multi-step array tracking — fruits, veggies & cart D2.1single

Trace every operation carefully. What does console.log(cart, fruits, veggies) output?

var cart   = [];
var fruits = ["apple", "banana", "mango"];
var veggies = ["carrot", "broccoli", "spinach"];

fruits.push("grape");       // step 1
veggies.unshift("kale");   // step 2

cart.push(fruits.pop());    // step 3
cart.push(veggies.shift()); // step 4
cart.unshift(fruits.shift()); // step 5

veggies.push(cart.pop());   // step 6

console.log(cart);
console.log(fruits);
console.log(veggies);
After step 1: fruits=[apple,banana,mango,grape]. Step 2: veggies=[kale,carrot,broccoli,spinach]. Step 3: fruits.pop()=grape → cart=[grape]. Step 4: veggies.shift()=kale → cart=[grape,kale]. Step 5: fruits.shift()=apple → cart=[apple,grape,kale]. Step 6: cart.pop()=kale → veggies=[carrot,broccoli,spinach,kale], cart=[apple,grape]. fruits=[banana,mango] (apple and grape were removed).
16
1D array — correct index notation D2.2single

These are regular (1D) arrays. Where is "X"?

var sectionA = [" ", " ", " ", "X"];
var sectionB = [" ", " ", " ", " "];
var sectionC = [" ", "O", " ", " "];
These are one-dimensional arrays, so only one index is needed. "X" is at index 3 (the 4th element, since arrays are 0-indexed). Double-bracket notation like [0][3] would only apply if each element were itself an array.
17
2D array — locate all X's and O's mid-game D2.2single

Given this tic-tac-toe board in progress, which answer correctly identifies all X and O positions?

var board = [
  ["X", " ", "O"],
  [" ", "X", " "],
  ["O", " ", "X"]
];
Row 0: X=[0][0], O=[0][2]. Row 1: X=[1][1]. Row 2: O=[2][0], X=[2][2]. The X's form a diagonal! Remember: first bracket is row, second is column, both 0-indexed.
18
Multi-step array trace — pop, shift, splice D2.1single

What does console.log(arr) print after all operations?

var arr = [10, 20, 30, 40, 50];
arr.pop();
arr.shift();
arr.splice(1, 1);
console.log(arr);
Start: [10,20,30,40,50]. pop() removes 50 → [10,20,30,40]. shift() removes 10 → [20,30,40]. splice(1,1) removes 1 element at index 1 (which is 30) → [20,40].
19
splice() on a 2D (nested) array D2.2single 
var board = [
  ["A1", "A2"],
  ["B1", "B2"],
  ["C1", "C2"]
];
board.splice(2, 0, ["new"]);
splice(2, 0, ["new"]) — start at index 2, delete 0 elements, insert ["new"]. This is a pure insertion. The new sub-array is inserted before the existing element at index 2 (["C1","C2"]), pushing it to index 3. splice works on any array, including 2D outer arrays.
20
What is the value of result? D2.1single 
var arr = [1, 2, 3];
var result = arr.push(4);
push() returns the new length of the array. After pushing 4, the array has 4 elements, so result = 4. Note that C and D both say "4" but for different reasons — D is correct because the reason matters.
21
Off-by-one loop — what is the sum? D2.1single

What does console.log(sum) output?

var nums = [10, 20, 30];
var sum = 0;
for (var i = 0; i <= nums.length; i++) {
  sum += nums[i];
}
console.log(sum);
The loop uses <= instead of <, so it runs when i=3 — but nums[3] is undefined. Adding a number to undefined produces NaN, and once sum becomes NaN, all further additions stay NaN.
22
unshift() with multiple arguments D2.1single 
var nums = [3, 4, 5];
nums.unshift(1, 2);
unshift() can accept multiple arguments — they are all inserted at the front, in the order given. There is no single-argument limit. Result: [1, 2, 3, 4, 5].
23
Build a homework supplies list with <br> D2.1single

Which loop correctly builds a string of supplies (each separated by a line break) that can be assigned to an element's innerHTML?

var homeworkSupplies = ["pencil", "ruler", "notebook"];
var output = "";

// ... loop goes here ...

document.getElementById("list").innerHTML = output;
Start at i=0 (not 1), use strict < (not <=), and the HTML tag must be a string: "<br>" with quotes. Without quotes, <br> is a syntax error. \n is a plain newline character — invisible in HTML. Note: the loop only builds the string; you still need .innerHTML = output after the loop to actually update the page.
24
!isNaN() validation — true or false for each value? D2.3single 
function validate(x) {
  return !isNaN(x) && x.toString().length <= 4;
}
!isNaN("1111") is true (parseable as number), length 4 ≤ 4 → true. !isNaN(8301) is true, length 4 ≤ 4 → true. !isNaN("ABCD") is false (NaN) — fails the first condition, short-circuits → false. Edge-case note: !isNaN(null) is actually true (null coerces to 0), but null.toString() would throw a TypeError — so this function isn't fully null-safe. For ITS exam purposes, assume inputs are strings or numbers.
Domain 3 Control Flow, Loops & Functions
25
Radicand function — place each line of code in the correct block D3.2ordering

The function has four blocks (A–D). Match each line of code to the slot it belongs in.

function radicand(a, b) {
  if ( ___blockA___ ) {
    var result = Math.sqrt(a);
    if ( ___blockB___ ) {
      ___blockC___;
    } else {
      ___blockD___;
    }
  } else if (b % 2 == 0) {
    return "b is even";
  } else {
    return "no solution";
  }
}

Available lines:  a >= 0  ·  b % 2 === 0  ·  Math.floor(result) === result  ·  return result + " is a perfect square"  ·  return result

blockA must be a >= 0 (includes zero). blockB checks whether the sqrt is a whole number: Math.floor(result) === result. If true → blockC: return result + " is a perfect square". Otherwise → blockD: return result (just the decimal root). Note: a > 0 incorrectly excludes sqrt(0)=0.
26
Radicand — trace the output for specific inputs D3.2single

Using the radicand function from Q25, what does radicand(9, 4) return?

a=9 >= 0 → enters first branch. result = Math.sqrt(9) = 3. Math.floor(3) === 3 is true → returns "3 is a perfect square". Even though b=4 is even, we never reach that branch because a passed the first check.
27
try / catch / finally — trace the output D3.4single 
var x = 10;

function multiply() {
  try {
    const y = 15;
    y = x * 2;
    console.log(y);
  } catch(e) {
    console.log(x * 3);
  } finally {
    console.log(x * 4);
  }
}
multiply();
Assigning to a const throws a TypeError. The try block is abandoned; catch runs: x*3=30. The finally block always runs regardless: x*4=40. Output: 30, 40.
28
for loop with continue — trace the output D3.1single 
var result = "";
for (var j = 0; j < 8; j++) {
  if (j == 2) continue;
  result += j + " ";
}
console.log(result);
continue skips the rest of the current iteration but does NOT end the loop. When j==2, that pass is skipped. The loop continues for 3–7. Compare to break, which would end the loop entirely.
29
Infinite loop — identify the bug D3.1single 
var sales;
var currentSales = 0;
sales = Math.round(prompt("Enter sales (-1 to quit): "));

function countSales() {
  while (sales !== -1) {
    currentSales += sales;
  }
  return currentSales;
}
The loop checks sales !== -1, but sales is never changed inside the loop body. If it enters (sales ≠ -1), it can never exit. The fix: prompt for a new value of sales inside the loop body.
30
switch / case — fall-through due to missing break D3.2single

A store gives a discount based on the day. What is the final value of discount when day = 2?

var day = 2;
var discount = 0;

switch(day) {
  case 1: discount = 10; break;
  case 2: discount = 20;
  case 3: discount = 30; break;
  case 4: discount = 40; break;
  default: discount = 0;
}
day=2 matches case 2: discount=20. But there is no break, so execution falls through into case 3: discount=30. Then break stops it. Final value: 30. This is why missing break is a common bug.
31
Compound boolean conditions — activity selector D3.2single

Rules: hike if sunny AND temp > 70 · golf if sunny AND temp <= 70 · bowling otherwise. Given sunny = true and temp = 70, what activity is selected?

var sunny = true;
var temp = 70;

if (sunny && temp > 70) {
  activity = "hike";
} else if (sunny && temp <= 70) {
  activity = "golf";
} else {
  activity = "bowling";
}
The hike condition requires temp > 70 (strictly greater). temp=70 fails this (70 is not greater than 70). The golf condition requires temp <= 70 — 70 IS less-than-or-equal to 70 ✓ — and sunny is true ✓. So activity = "golf".
32
multiply() and divide() — don't mix up parameter names D3.3single 
function add(a, b)      { return ______; }
function multiply(x, y) { return ______; }
function divide(n, d)   { return ______; }
Each function must use its own parameter names. add(a,b)→a+b; multiply(x,y)→x*y; divide(n,d)→n/d. Mixing names from other functions is the classic exam trap here.
33
do…while loop — trace the final result D3.1single

What does console.log(count) output?

var count = 0;
do {
  count++;
} while (count < 1);
console.log(count);
In a do...while, the body executes first, then the condition is checked. count starts at 0: body runs → count=1. Now check: 1 < 1 is false → loop exits. Output: 1. A regular while loop would have output 0 because the condition fails immediately.
34
Updating a property of a nested object passed to a function D3.3single

What does console.log(student.courses[1]) output after calling the function?

var student = {
  name: "Alex",
  courses: ["Math", "English", "Science"]
};

function updateCourse(s, index, newCourse) {
  s.courses[index] = newCourse;
}

updateCourse(student, 1, "History");
console.log(student.courses[1]);
In JavaScript, objects (and arrays) are passed by reference. Inside updateCourse, s points to the same object as student. Changing s.courses[1] directly mutates the original. courses[1] is now "History".

Domain 4 DOM Manipulation & Window Object
37
window vs. document — which shows a dialog? D4.1single

Which object is responsible for browser-level dialogs like alert()?

alert() is shorthand for window.alert(). The window object represents the browser window and hosts all global functions. The document object is a child of window and controls HTML content — not dialogs.
38
document object — which two statements are true? D4.1multi
A The document object contains all other objects on the page (all DOM nodes)
B The window object is a child of the document object
C Every HTML element and its attributes are nodes that descend from the document object
D Only HTML elements descend from document — attributes are separate
A is true: the document is the root of the DOM tree and contains all page objects (elements, text nodes, etc.). C is true: both elements AND their attributes are nodes in the DOM tree. B is backwards — document is a property of window, not the other way. D is false — attributes are also DOM nodes.
39
Event bubbling — does the div's mouseover fire when hovering the button inside it? D4.2single

A <div> has an onmouseover listener. Inside it is a <button> with an onclick listener. The user moves the mouse over the button (but does not click). What happens?

This is event bubbling. Mouse events on a child element bubble up through parent elements. Hovering the button triggers mouseover on the button, which then bubbles to the div — firing the div's onmouseover. The button's onclick does NOT fire because no click occurred.
40
innerHTML vs. value vs. textContent D4.3single

A user types in an <input> field. You want to display their text in a <section> element, then hide the input. Which code is correct?

Use .value to read what a user typed in an <input>. Use .textContent (safer — no HTML parsing) or .innerHTML to set content in a non-input element like <section>. input.hidden = true is the modern boolean property for hiding — equivalent to style.display = "none" but cleaner to write. Both approaches hide the element; your curriculum may use either.
41
insertBefore — add element as first child D4.3single

The body's only child is a <div>. You want to insert a new element before it. Which is correct?

appendChild always adds to the end. The full syntax is parentNode.insertBefore(newNode, referenceNode) — it must be called on the parent, not the reference node itself (a common mistake). Both arguments are required; omitting the reference node will cause unexpected behavior.
42
createElement → setAttribute → appendChild — correct order D4.3single
(1) Create the element. (2) Configure it with attributes. (3) Attach it to the DOM. You can't setAttribute on something that doesn't exist yet, and appending before configuring is valid but not the standard pattern.
43
var hoisting — output when variable declared after use D4.1single 
var firstName = "Jane";
var lastName  = "Doe";
console.log(firstName, lastName, salary);
var salary = 50000;
var declarations are hoisted — the declaration var salary is moved to the top of scope, but the assignment = 50000 is not. So salary exists at the time of console.log (no error), but its value is undefined.
44
onmouseout — which event fires when the mouse leaves? D4.2single
onmouseout fires when the pointer leaves an element. onmouseover fires on entry. onblur fires when a form field loses keyboard focus. onmouseup fires when a mouse button is released after clicking.
45
getElementById vs. getElementsByClassName — return types D4.3single
IDs must be unique per page — getElementById returns a single element. Class names can repeat — getElementsByClassName returns an HTMLCollection. To get a single item from a collection, use index notation: [0], [1], etc.
46
onfocus and onblur — when do they fire? D4.2single
onfocus fires when a user clicks into or tabs into a form field. onblur fires when they click away or tab out. These are focus events, not mouse position events — they respond to where the keyboard interaction is, not the cursor.
47
screen.width — what does it measure? D4.1single
screen.width = full physical display width. window.innerWidth = browser viewport width. document.body.offsetWidth = content width. Three different measurements — screen.width is the hardware screen total.
48
Where can a <script src="..."> tag be placed? D4.1multi

Select ALL valid locations (choose two).

A Inside a <style> block
B In the <head> tag
C Inside another .js file
D At the end of the <body>
A <script> tag is HTML and can only go in HTML files — in the <head> (runs before DOM loads) or at the bottom of <body> (recommended — DOM is ready). It cannot go inside a CSS <style> block or inside a .js file.
Domain 5 Forms, Validation, OOP & HTTP
49
GET vs. POST — which statement is true? D5.2single
GET: visible in URL, cached, bookmarkable, limited data size. POST: body-based, not cached, not in browser history, no length restriction. For passwords and sensitive data, always use POST.
50
Valid form submission destinations + preventDefault D5.2multi

Select ALL true statements about form submission (choose three).

A A form can submit to another webpage, a server-side script, or a database via a script
B A form can submit to "another form" on the same page
C Calling event.preventDefault() in the submit handler stops the form from submitting to the server
D event.preventDefault() is commonly used when you want to validate with JavaScript before allowing submission
A: correct destinations — page, script, or database. C: preventDefault() stops the default browser action (page reload / server submit). D: this is exactly its primary use case — validate first, then submit programmatically if valid. B is false — forms submit to URLs, not to other form elements.
51
formElement.submit() — button required? D5.1single

A form has no submit button, but a script calls myForm.submit(). What is true?

formElement.submit() submits the form programmatically — no button needed. Key exam concept: calling .submit() directly bypasses HTML5 constraint validation entirely. That means required attributes, type="email" format checks, and pattern attributes are all skipped. The browser only enforces those when a user clicks a submit button. This is a common certification trap question.
52
Making a form field required D5.1single
required is a boolean HTML5 attribute — you write just the word, no value needed. It's equivalent to required="" or required="required". The browser blocks form submission if the field is empty.
53
new Date() — months are 0-indexed D5.1single

Which creates a Date object for January 1, 2025?

new Date(year, month, day) — months are 0-indexed: January=0, February=1, … December=11. Always use the 4-digit year. new Date(2025, 1, 1) would be February 1st, not January.
54
Input type for masked password entry D5.1single
type="password" shows bullet/asterisk characters instead of the actual input. type="hidden" hides the entire field from view (used for data not shown to users, like CSRF tokens). These are very different purposes.
55
When should a field be pre-populated? D5.1single
Pre-population saves the user time when the default is almost always correct. Country fields, today's date, and known preferences are classic examples. Users can still override the value — it's just a helpful starting point.
56
OOP — extending a class: does the subclass need super()? D5.3single

A Rabbit class extends Animal. The Rabbit constructor does not call super(). What happens when you do new Rabbit("Bugs")?

class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Rabbit extends Animal {
  constructor(name) {
    // super(name) is NOT called
    this.type = "rabbit";
  }
}
In JavaScript, if a subclass has a constructor, it must call super() before any reference to this. Without it, JavaScript cannot initialize the inherited this object and throws: "Must call super constructor in derived class before accessing 'this'".
57
eval() — what does it do with form input? D5.1single 
eval("var a = " + document.getElementById("a").value);
eval("var b = " + document.getElementById("b").value);
eval() executes its string argument as JavaScript. eval("var a = " + "5") effectively runs var a = 5 in scope, dynamically declaring variables from user input. Industry note: eval() is considered dangerous and is often called "eval is evil" — it can execute any injected code, making it a major security vulnerability. The ITS exam tests that you know what it does, not that you should use it.
58
Form action attribute — what does it specify? D5.2single
action="submit.php" is the destination URL. method specifies GET/POST. onsubmit handles validation. Three different attributes — each does one job.
59
OOP — what does this refer to inside a class method? D5.3single 
class Car {
  constructor(make, model) {
    this.make  = make;
    this.model = model;
  }
  describe() {
    return this.make + " " + this.model;
  }
}
var myCar = new Car("Toyota", "Corolla");
Inside a class method, this is the instance — the specific object created with new Car(...). myCar.describe() → this = myCar, so it returns "Toyota Corolla". Each instance has its own property values.
60
var / let / const — which combination is entirely true? D1.1 / D5single
var: function-scoped, hoisted, can be re-declared. let: block-scoped, not hoisted to usable state. const: block-scoped, cannot be reassigned (though object/array contents can be mutated). These scoping rules are tested across domains.
