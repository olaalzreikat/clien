= vs == vs === Assignment vs Comparison
+
The single = assigns a value. The double == compares values (loose). The triple === compares value AND type (strict). This is one of the most common exam topics.
// = ASSIGNMENT — stores a value var score = 100; var name = 'Alex'; var isLoggedIn = false; // == LOOSE EQUALITY — only checks value console.log(0 == false); // true (both "falsy") console.log('5' == 5); // true (string converted) // === STRICT EQUALITY — value AND type console.log(0 === false); // false (number ≠ boolean) console.log('5' === 5); // false (string ≠ number)
= is ONLY for assignment. Never use it inside an if condition.
== can give unexpected results because it converts types.
=== is safer — use it for comparisons when type matters.
Arithmetic Math Operators & Modulus
+
JavaScript uses * for multiplication (NOT x), / for division, and % for modulus (remainder after division).
var a = 10; var b = 3; console.log(a + b); // 13 addition console.log(a - b); // 7 subtraction console.log(a * b); // 30 multiplication (* not x!) console.log(a / b); // 3.33... division console.log(a % b); // 1 modulus (10 ÷ 3 = 3 remainder 1) // Modulus real use: check even/odd var num = 8; if (num % 2 === 0) { console.log('Even!'); } // Even! // Increment & Decrement var x = 5; x++; // x is now 6 x--; // x is now 5 again // Compound assignment shortcuts x += 10; // same as x = x + 10 x *= 2; // same as x = x * 2
⚠️ parseInt('7.9') returns 7 — it CUTS OFF the decimal, does NOT round up!
try/catch/finally Exception Handling
+
Wrap risky code in try. If an error occurs, catch handles it. finally ALWAYS runs regardless.
function getPracticeHours() { 'use strict'; // MUST be first, before try try { var hours = parseInt(document.getElementById('input').value); if (isNaN(hours)) throw 'Not a number!'; console.log('Hours: ' + hours); } catch(error) { console.log('Error: ' + error); // only if error } finally { document.getElementById('status').innerHTML += 'Done!'; // ↑ THIS ALWAYS RUNS no matter what } }
✓ finally always executes — perfect for cleanup tasks like resetting UI or closing connections.
BOM Browser Dialog Boxes
+
// alert — shows message, no return value alert('Welcome to the site!'); // prompt — collects user input (returns string or null) var name = prompt('What is your name?'); // confirm — OK = true, Cancel = false var answer = confirm('Are you sure you want to delete?'); if (answer) { console.log('User clicked OK — deleting!'); } else { console.log('User clicked Cancel'); }
Only 3 dialog types: alert, prompt, confirm. "Alarm" and "error" are NOT dialog types.
confirm() returns a boolean. prompt() returns a string (or null if cancelled).

Data Types null vs undefined & typeof
+
// UNDEFINED — declared, never assigned var subtotal; console.log(subtotal); // undefined console.log(typeof subtotal); // 'undefined' // NULL — intentionally empty var cart = null; console.log(typeof cart); // 'object' (quirk!) // typeof for each type console.log(typeof 42); // 'number' console.log(typeof 'hello'); // 'string' console.log(typeof true); // 'boolean' console.log(typeof myFunc); // 'function' // Number.isInteger console.log(Number.isInteger(5)); // true console.log(Number.isInteger(5.5)); // false
✓ All JavaScript numbers are stored as floating point decimals internally — even 5 is stored as 5.0
Math Object Built-in Math Methods

Date Object Creating, Reading & Formatting Dates

⚠️ January = 0, February = 1, ... December = 11. Always add 1 when displaying the month!

if/else Decision Statements
+
// Basic if — only runs if TRUE if (score >= 90) { console.log('A grade'); } // if → else if → else (always this order!) if (score >= 90) { console.log('A'); } else if (score >= 80) { console.log('B'); } else if (score >= 70) { console.log('C'); } else { console.log('Failing'); // fallback } // Combining with logical operators if (age >= 18 && hasId) { // AND — both must be true console.log('Access granted'); } if (isAdmin || isMod) { // OR — either can be true console.log('Elevated access'); } if (!isLoggedIn) { // NOT — flips the boolean console.log('Please log in'); }
switch Multiple Cases
+
var day = new Date().getDate(); // day of month switch (day) { case 1: msg = '10% off today!'; break; // ← CRITICAL! Without this, falls through case 15: msg = '15% off today!'; break; case 7: msg = '7% off today!'; break; default: msg = 'No special today.'; // runs if no case matches }
⚠️ Missing a break causes "fall-through" — the code keeps running into the next case!
Loops for, while, do-while + break/continue
+
// FOR — runs a set number of times for (var i = 0; i < 5; i++) { console.log('i is', i); // 0,1,2,3,4 } // WHILE — checks condition first (may never run) var count = 0; while (count < 3) { console.log(count); count++; } // DO-WHILE — runs AT LEAST ONCE, then checks var x = 100; do { console.log('This runs once!'); // runs even though x>3 } while (x < 3); // break — exits loop immediately for (var i = 0; i < 10; i++) { if (i === 5) break; // stops at 5 console.log(i); // 0,1,2,3,4 } // continue — skips ONE iteration for (var i = 0; i < 5; i++) { if (i === 2) continue; // skips 2 console.log(i); // 0,1,3,4 }

Accessing Getting Elements from the DOM
+
// getElementById — returns ONE element var el = document.getElementById('myDiv'); // Other methods — return COLLECTIONS (not single elements) var byName = document.getElementsByName('email'); var byClass = document.getElementsByClassName('card'); var byTag = document.getElementsByTagName('p'); // Modify content el.innerText = 'Plain text only'; // text, no tags el.innerHTML = '<b>Bold text</b>'; // HTML parsed el.textContent = 'Includes hidden text'; // incl display:none // Modify attributes & style el.setAttribute('class', 'highlight'); el.style.color = 'red'; el.style.fontSize = '18px';
⚠️ innerText vs textContent: innerText only shows visible text. textContent includes text from display:none elements.
DOM Manipulation Create, Add, Remove, Replace
+
// Create — element exists in MEMORY only, not yet in DOM var newPara = document.createElement('p'); newPara.innerText = 'I am new!'; // Add to DOM var list = document.getElementById('myList'); list.appendChild(newPara); // add as LAST child list.insertBefore(newPara, list.firstChild); // add at START // Remove var item = document.getElementById('oldItem'); item.remove(); // simplest way list.removeChild(list.firstChild); // remove specific child // Replace list.replaceChild(newPara, oldPara); // swap elements // outerHTML replaces the ENTIRE element document.getElementById('old').outerHTML = '<div>New!</div>';
Events Bubbling, Capturing & addEventListener
+
// Bubbling (default): child → parent → grandparent element.addEventListener('click', handler, false); // Capturing: grandparent → parent → child (true = capturing) element.addEventListener('click', handler, true); // Note: event name has NO 'on' prefix here! // NOT 'onclick' — just 'click' // Stop bubbling element.addEventListener('click', function(e) { e.stopPropagation(); // stops traveling up }); // Cancel default browser behavior (e.g. link navigation) link.addEventListener('click', function(e) { e.preventDefault(); // stops the link from navigating }); // Common events element.onclick // click element.onblur // lost focus element.onfocus // gained focus element.onkeydown // key pressed (use event.code) element.onmouseover // mouse entered element

Forms Accessing & Reading Form Values
+
// Access all forms on the page var allForms = document.forms; // collection var first = document.forms[0]; // by index var named = document.forms['myForm']; // by name // Read an input value var name = document.forms['customerForm']['firstName'].value; // Preset a value document.forms['customerForm']['firstName'].value = 'John'; // Multi-select: must loop through options var sel = document.forms['myForm']['colors']; var chosen = []; for (var i = 0; i < sel.options.length; i++) { if (sel.options[i].selected) { chosen.push(sel.options[i].value); } }
Validation isNaN, localeCompare, length
+
// isNaN() — returns TRUE if NOT a number console.log(isNaN(42)); // false — IS a number console.log(isNaN('42')); // false — numeric string console.log(isNaN(true)); // false — true → 1 console.log(isNaN('hello')); // TRUE — not a number! console.log(isNaN(undefined));// TRUE — can't convert console.log(isNaN('')); // false — empty → 0 // localeCompare — language-aware comparison // 0 = equal, -1 = arg comes AFTER, 1 = arg comes BEFORE console.log('apple'.localeCompare('apple')); // 0 console.log('apple'.localeCompare('banana')); // -1 console.log('banana'.localeCompare('apple')); // 1 // Case-insensitive comparison var input = 'PARIS'; if (input.toLowerCase() === 'paris') { console.log('Match!'); // works! } // Empty string check if (input.length === 0) { alert('Required!'); }
Submission GET vs POST, onsubmit Validation
+
<!-- Form attributes --> <form name="myForm" action="/submit" method="POST" target="_blank" onsubmit="return validateForm()"> <!-- return validateForm() — NOT just validateForm()! Without 'return', false is ignored and form submits --> </form> // Validation function function validateForm() { var name = document.forms['myForm']['firstName'].value; if (name.length === 0) { alert('Name is required!'); return false; // BLOCKS submission } return true; // ALLOWS submission }
GET: data visible in URL (?name=John). Good for searches.
POST: data in request body, hidden from URL. Good for passwords, sensitive data.
target="_blank" opens response in new tab. target="_self" (default) = same tab.
