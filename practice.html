CSS transform functions

FunctionEffect
translate(x,y)Moves element. No layout shift.
scale(x,y)Resizes. 1=none, 2=double, 0.5=half
rotate(deg)Clockwise. Negative = counter-CW

rotateY(deg)3D flip — needs perspective on parent
matrix(a,b,c,d,e,f)scaleX, skewY, skewX, scaleY, transX, transY
⚠ zoom is NOT a matrix() arg. 6 args only: scaleX, skewY, skewX, scaleY, translateX, translateY

FilterEffect

invert(100%)Photo negative effect
⚠ drop-shadow() follows shape (great for PNGs). box-shadow always rectangular.
