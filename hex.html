Foundations

What Are Number Systems?

The Big Picture

A number system is just a way to represent a quantity using symbols. The amount "twelve" is the same regardless of how you write it — the representation changes, not the value itself.

Computers only understand electricity: ON or OFF. We represent those as 1 and 0. Everything on a screen — text, images, colors, sounds — is stored as patterns of 1s and 0s underneath.

Chapter 01

Decimal → 8-bit Binary

Plain English Explanation

You keep dividing your number by 2 until you reach 0. Every time you divide, write down the remainder — it'll always be either 0 or 1 because you're dividing by 2. Once you've divided all the way down, read the remainders backwards (last one first). If you end up with fewer than 8 digits, fill in zeros on the left side until you have exactly 8.

Those 8 digits — your byte — are the binary number. Think of it like peeling off the rightmost bit one at a time, then stacking them back up in reverse.

Divide by 2 → collect remainders → read bottom-up → pad to 8 bits with leading zeros.
Example: Convert 13 to binary
13 ÷ 2 = 6 remainder 1 ← write this down
 6 ÷ 2 = 3 remainder 0
 3 ÷ 2 = 1 remainder 1
 1 ÷ 2 = 0 remainder 1 ← start reading from here (bottom)
Remainders bottom-up: 1101 → pad to 8 bits: 00001101

CONCEPT — bit position weights
Why does each position matter?

Each bit position has a weight that is double the one to its right. Position 0 (rightmost) = 1, position 1 = 2, position 2 = 4… up to position 7 = 128. When a bit is 1, its weight is added to the total. When it's 0, nothing is added. This is why flipping the leftmost bit changes the value by 128 but flipping the rightmost only changes it by 1.

128+64+32+16+8+4+2+1 = 255 — the maximum value of one byte (8 bits).

Chapter 02

Binary → Decimal

Plain English Explanation

Look at each bit from right to left. Each position has a value that doubles as you move left: 1, 2, 4, 8, 16, 32, 64, 128. If the bit is a 1, add that position's value to your running total. If the bit is a 0, skip it — it adds nothing.

Go through all 8 bits, collecting values only where you see a 1, then add them all up. That sum is your decimal answer. Think of each lit-up bit as saying "include me!" and each dark bit as saying "ignore me."

For every bit that is 1: add its position value (1, 2, 4, 8, 16, 32, 64, or 128). Sum all collected values.
Example: Convert 00001101 to decimal
Position 7 (128): bit = 0 → skip
Position 6 (64): bit = 0 → skip
Position 5 (32): bit = 0 → skip
Position 4 (16): bit = 0 → skip
Position 3 (8): bit = 1 → add 8
Position 2 (4): bit = 1 → add 4
Position 1 (2): bit = 0 → skip
Position 0 (1): bit = 1 → add 1
Total: 8 + 4 + 1 = 13

Chapter 03

Binary → Hexadecimal

Plain English Explanation

Hexadecimal (hex) is base-16, meaning it has 16 possible symbols per digit: 0–9 for values zero through nine, then A=10, B=11, C=12, D=13, E=14, F=15. Programmers love hex because 4 binary bits map perfectly to exactly 1 hex digit. No leftovers, no rounding — it's a clean fit.

So to convert: chop your 8 bits in half — left 4 bits and right 4 bits. Each group of 4 (called a nibble) becomes one hex digit. Look up each nibble's decimal value, find its hex symbol, then write both hex digits side by side.

Split 8 bits into two 4-bit halves (nibbles). Each nibble → one hex digit. Join both hex digits.
Example: Convert 10101111 to hex
Split: 1010 | 1111
Left nibble 1010 = 8+2 = 10 decimal = A in hex
Right nibble 1111 = 8+4+2+1 = 15 decimal = F in hex
Join: AF

Chapter 04

Hex → Binary & Decimal

Plain English Explanation — Hex → Binary

This is exactly the reverse of the nibble trick from Chapter 3. Take each hex digit one at a time and replace it with its 4-bit binary version. Every single hex digit always expands into exactly 4 bits — even if the value is small. So 3 becomes 0011, not just 11. Put both 4-bit groups together and you have your full 8-bit binary number.

Plain English Explanation — Hex → Decimal

A 2-digit hex number works just like a 2-digit decimal number, except the "place value" is 16 instead of 10. In decimal, the left digit is worth ×10. In hex, the left digit is worth ×16. So convert each hex digit to its decimal value (remember A=10 through F=15), multiply the left digit by 16, and add the right digit.

Hex → Binary: expand each digit into its 4-bit pattern. Join both results.
Hex → Decimal: (left digit × 16) + right digit.
Example: Convert AF to binary and decimal
A = 10 in decimal → 4-bit binary: 1010
F = 15 in decimal → 4-bit binary: 1111
Binary: join them → 10101111
Decimal: (10 × 16) + 15 = 160 + 15 = 175

Chapter 05

RGB Color → Hexadecimal

Plain English Explanation

A color on screen is made by mixing Red, Green, and Blue light. Each channel is a number from 0 (completely off) to 255 (full brightness) — exactly one byte each. An HTML hex color like #FF5733 is just three 2-digit hex numbers joined in a row: first two digits = Red, next two = Green, last two = Blue.

To convert: take each channel (R, G, B) separately and convert its decimal value (0–255) to a 2-digit hex value (00–FF). To get that 2-digit hex, divide by 16 — the quotient is the first hex digit, the remainder is the second. If either digit would be 10–15, use A–F. Then stick a # in front and join all three pairs.

Convert R, G, B each separately to 2-digit hex. Join them: #RRGGBB.
Each channel: value ÷ 16 → quotient = first hex digit, remainder = second hex digit.
Example: rgb(230, 57, 70) → hex
R = 230: 230÷16 = 14 r 6 → 14=E, 6=6 → E6
G = 57: 57÷16 = 3 r 9 → 3=3, 9=9 → 39
B = 70: 70÷16 = 4 r 6 → 4=4, 6=6 → 46
Join with #: #E63946

Chapter 06

Reference & Cheat Sheet

ALL 6 RULES — quick reference
1
Dec → Bin: Divide by 2 repeatedly. Write each remainder. Read remainders bottom-up. Pad left with 0s to 8 bits. Each remainder is the next bit from right to left.
2
Bin → Dec: For every bit that is 1, add its position weight (2⁰=1, 2¹=2, 2²=4, 2³=8, 2⁴=16, 2⁵=32, 2⁶=64, 2⁷=128). Sum all collected values.
3
Bin → Hex: Split 8 bits into left nibble (bits 7–4) and right nibble (bits 3–0). Convert each nibble to decimal, look up its hex symbol. Join both hex digits.
4
Hex → Bin: Reverse of rule 3. Expand each hex digit to its 4-bit binary pattern (always 4 digits — pad with zeros if needed). Join both 4-bit results.
5
RGB → Hex: Convert each channel (R, G, B) from decimal to 2-digit hex independently using ÷16. Prefix result with #. Format: #RRGGBB.
✓
Hex → Dec: (First digit × 16) + second digit. Remember: A=10, B=11, C=12, D=13, E=14, F=15. Or convert to binary first, then apply rule 2.
